요청 방법

  1. 게임 닉네임과 연결 방식(게스트 / Google / Apple)을 적어주세요. 알 수 있다면 플레이어 ID 또는 친구 코드를 함께 적어주세요.
  2. 접근할 수 없다면 그 사실과 마지막 이용 시각·기기 모델을 알려주세요. 소유 확인에 필요한 최소 추가 정보만 안내합니다.
  3. 전체 계정 삭제인지, 계정을 유지하고 특정 데이터만 삭제하려는지 알려주세요.
  4. 운영자가 소유 확인 후 삭제 범위·영향과 예외 보관 기록을 안내하고 처리 결과를 회신합니다.
보안: 비밀번호, 토큰, 인증 코드, 신분증, 카드 번호 또는 영수증 원문 전체를 보내지 마세요. 이 페이지는 계정 정보를 자동 수집·전송하지 않습니다. 이메일은 내용을 확인한 뒤 사용자가 직접 발송합니다.

삭제 범위와 영향

삭제는 GameStack 계정 및 연결된 개인정보, 서버 진행·친구·메시지 등 관련 데이터의 삭제와 Firebase 등 제공자의 관련 개인정보 삭제 요청을 포함합니다. 단순 비활성화나 로그아웃으로 대신하지 않습니다. 이후 기존 진행과 접근을 복구할 수 없을 수 있으며 상대방이 별도로 저장한 대화 사본까지 회수할 수는 없습니다.

소유 확인 완료 후 일반적으로 30일 이내 처리를 목표로 합니다. 법령상 보존해야 하는 구매·환불 기록, 필요한 보안·신고·분쟁 증거는 허용 목적·기간에 한해 제한적으로 보관할 수 있으며 해당 사유를 답변에서 안내합니다.

기기 데이터와 스토어

앱 제거·기기 데이터 초기화는 기기 캐시·설정을 지우지만 서버 계정을 삭제하지 않습니다. Google·Apple 연결 해제도 계정 삭제와 다릅니다. 계정 삭제 자체가 스토어 환불·구독 취소를 요청하는 것은 아닙니다. 필요한 환불·구독 관리는 스토어에서 별도로 진행하세요. 개인정보 삭제를 위해 구매나 환불을 먼저 완료할 필요는 없습니다.
